# JAS-mine Reference

These pages explain the library facilities used by SimPaths. Start with the user or developer guide for a model task; use this section when you need to understand the underlying mechanism.

- [Regression Library](regression-library.md): coefficient maps, model types and outcome evaluation.
- [Alignment Library](alignment-library.md): algorithms for matching aggregate targets.
- [Statistical Package](statistical-package.md): data sources, aggregates and updating statistics.
- [Querying the Database](querying-database.md): entity relationships and safe database inspection.
- [Saving outputs](saving-outputs.md): persistence and data export.
- [Enums](enums.md): categorical values and persistence compatibility.

Library examples describe general patterns unless explicitly tied to a SimPaths class. The project's `pom.xml` determines the library version in use; see [Updating JAS-mine](../developer-guide/jasmine/updating-jasmine.md) before changing it.
