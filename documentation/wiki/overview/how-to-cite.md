# How to Cite SimPaths

<section class="cite-section cite-section--primary" markdown>

## SimPaths reference paper

<p class="cite-intro">If you use SimPaths or derived work, please cite the reference paper below.</p>

<div class="cite-primary" markdown>

<p class="cite-label">Recommended citation</p>

<p class="cite-entry" markdown>Bronka P, van de Ven J, Kopasker D, Katikireddi SV, Richiardi M (2025). [SimPaths: an open-source microsimulation model for life course analysis](https://microsimulation.pub/articles/00318). *International Journal of Microsimulation*, 18(1): 95-133. DOI: [10.34196/ijm.00318](https://doi.org/10.34196/ijm.00318).</p>

</div>

</section>

<section class="cite-section" markdown>

## Further references

<p class="cite-entry" markdown>For related methodological and applied publications, see [Further references on the Research page](../research/index.md#further-references). Cite the papers relevant to the processes and application used in your work, alongside the model reference above.</p>

<p class="cite-entry">Also report the model release or commit, input and parameter versions, policy scenario and run configuration so that the analysis can be reproduced.</p>
